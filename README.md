# Graph Theory & Network Analysis

This repository contains **postgraduate research** and algorithmic implementations developed at **Gauhati University**. The project focuses on the intersection of discrete mathematics and computational efficiency, specifically applied to social network topologies.

## 🎓 Research Summary (Finalized May 2024)
The primary objective of this study was to optimize pathfinding within dynamic graphs. By implementing a priority-queue-based Dijkstra's Algorithm, the project demonstrates a robust method for determining optimal routing paths with a time complexity of $O(E \log V)$.

### Core Technical Features
- **Social Connectivity Mapping:** Modeled undirected graphs to simulate real-world social interactions.
- **Algorithmic Optimization:** Leveraged Python's `heapq` module to ensure high-performance node traversal and minimal memory overhead.
- **Weighted Edge Analysis:** Capability to handle varied connection strengths between nodes for realistic network simulations.

## 🛠️ Tech Stack
- **Language:** Python 3.10+
- **Key Modules:** `heapq` (Binary Heap), `math`
- **Domain:** Graph Theory, Network Optimization
